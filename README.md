# تحلیل‌گرام

## راه‌اندازی (Cloudflare Pages)
1. ریپو را به Pages وصل کن (بدون Build command، Output directory = `/`).
2. در Settings → Bindings یک **D1 database** با نام متغیر `DB` وصل کن.
3. در Settings → Variables and Secrets (به‌صورت Secret):
   - `ADMIN_PASSWORD` — رمز قوی (۱۲+ کاراکتر، حروف بزرگ/کوچک، عدد، نماد)
   - `SESSION_SECRET` — رشتهٔ تصادفی ۳۲+ کاراکتری
   - `MAIL_URL` و `MAIL_KEY` — برای ایمیل کد تأیید ثبت‌نام
4. دیتابیس خودکار ساخته/به‌روز می‌شود؛ نیازی به اجرای SQL نیست (`db/schema.sql` فقط مرجع است).
5. بعد از دیپلوی برو `/admin` ← تب «امنیت» ← **ورود دومرحله‌ای** را فعال کن.

## حالت «در حال به‌روزرسانی»
دیگر لازم نیست فایل‌ها را جابه‌جا کنی. در `/admin` ← امنیت ← تیک «نمایش در حال به‌روزرسانی».
ادمین (که لاگین است) سایت را عادی می‌بیند، بقیه صفحهٔ بروزرسانی.

## اگر موبایل 2FA را گم کردی
متغیر `ADMIN_2FA_OFF` = `1` را موقتاً بگذار، با رمز وارد شو، 2FA را دوباره راه بینداز و متغیر را پاک کن.

## امنیت
CSP و هدرهای امنیتی، قفل ۱۵ دقیقه‌ای بعد از ۵ رمز اشتباه، محدودیت نرخ ثبت‌نام/ورود/تیکت، مسدودسازی IP،
نشست‌های ادمین قابل ابطال، بلاک مسیرهای اسکنر (`.env`, `.git`, `.sql`, `wp-*` …) و گزارش رویدادها.
